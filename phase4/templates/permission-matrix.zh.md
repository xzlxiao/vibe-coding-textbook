# 权限矩阵模板

> 用法：每个工具一行。三判据（影响半径 × 可逆性 × 可观测性）算出复核档，**再决定是收窄作用域还是删掉工具**。
> 判据不看"这个动作重不重要"——重要性是主观的；半径、可逆性、可观测性是可核对的。

**列怎么填**

- **作用域**：写"能碰什么"，尽量带硬上限（例：`单笔 ≤50 元，单日 ≤500 元`）。写"读订单"不合格。
- **凭据生命周期**：长寿命 / 短寿命（多久）/ 每次交换。**长期有效 = 每一次都是一次可被复制的凭据。**
- **影响半径**：1 个对象 / 1 个服务（千行级）/ 全库、全租户、已对外
- **可逆性**：可回滚（有备份或幂等）/ 需快照恢复 / 不可逆（对外已发生）
- **可观测性**：有日志+告警 / 只有日志 / 看不见。**"有日志"不算可观测，"有人被叫醒"才算。**
- **复核档**：自动放行 / 自动+事后审 / 单人在环 / 双人+预演 / 默认禁止
- **kill switch**：一按就停的具体动作（关哪个 flag、撤哪个密钥）。**没演练过 = 没有。**
- **单次最大影响**：一次调用最远能造成什么（例：`1 行订阅状态`）

## 复核档判定矩阵

| | 影响半径：1 个对象 | 1 个服务 | 全库 / 已对外 |
|---|---|---|---|
| **可回滚** | 自动放行 | 自动 + 事后审 | 单人在环 |
| **需恢复** | 自动 + 告警 | 单人在环 | 双人 + 预演 |
| **不可逆** | 单人在环 | 双人 + 预演 | 默认禁止 |

**修正项**：可观测性为"只有日志"或"看不见"时，**升一档**（已在最高档则维持）。
