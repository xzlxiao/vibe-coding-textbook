## 判读

| 判定 | 说明 |
|---|---|
| 健康 | 401/403，或 200 但空集 |
| 可疑 | 200 且有数据、但不确定是不是公开字段；**"可疑"不是"没事"，它是"我还没看懂"** |
| 已失守 | 200 且拿到了非公开数据 |

## 接进 CI 的那条命令

```bash
python3 code/ch09/replay_probe.py --base-url "$SB_URL" --anon-key "$SB_ANON" --table <表名>
```

退出码：0 = 三步全健康；1 = 至少一步可疑；2 = 至少一步已失守。
