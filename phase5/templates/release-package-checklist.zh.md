> 规则：阻断项（标 ★）全过才可上线；非阻断项可带缺口上线，但必须写进第一周待办。

## 一、能退回去

- [ ] ★ R1 上一次发布可一键回滚（验证：预发执行一次并计时）
- [ ] ★ R2 数据库迁移可回滚或已前向兼容（验证：脚本中无 DROP / 改类型）
- [ ] ★ R3 上一版镜像保留 ≥ 7 天（验证：查看保留策略）
- [ ] R4 特性开关可关闭新功能而不发版（验证：关掉后旧路径正常）

## 二、看得见

- [ ] ★ O1 四个黄金信号已上仪表盘（验证：打开面板，四图有数据）
- [ ] ★ O2 错误率告警 5 分钟内可达（验证：造一次 5xx，计时）
- [ ] O3 单请求成本可在日志里查到
- [ ] O4 上游超时有独立告警
- [ ] O5 有「今天花了多少」的日汇总

## 三、有后路

- [ ] ★ B1 备份任务最近 24 小时成功（验证：日志中有 success 且大小 > 1MB）

- [ ] ★ B3 模型 API 不可用时有降级策略（验证：拔掉上游，看用户看到什么）
- [ ] B4 支付失败有明确提示与重试

## 四、说得清

- [ ] ★ L1 价格页写明计费单位与周期

- [ ] ★ L4 有退款政策与联系方式
- [ ] ★ L5 AI 交互处有「这是 AI」的告知
- [ ] L6 生成内容带标识
- [ ] ★ L7 公示所用模型名称与备案号/上线编号
